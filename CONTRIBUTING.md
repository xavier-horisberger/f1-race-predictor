# Collaborazione

1. Aggiornare `main`: `git switch main` e `git pull origin main`.
2. Aprire un branch: `git switch -c feature/nome-breve`.
3. Implementare una modifica piccola e testabile; non committare dati pesanti.
4. `git add .`, `git commit -m "feat: descrizione"`, `git push -u origin feature/nome-breve`.
5. Aprire una Pull Request verso `main`; chiedere una review all'altro membro.
6. Dopo il merge aggiornare `main` prima di iniziare altre attività.

Per notebook: eseguire le celle in ordine, rimuovere output enormi e salvare note Markdown che spiegano scelte, metriche e risultati.
